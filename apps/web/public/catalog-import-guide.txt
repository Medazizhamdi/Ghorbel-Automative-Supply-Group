GHORBEL — IMPORT DU CATALOGUE DE PIÈCES
========================================

Le fichier catalog-import-template.csv utilise le point-virgule (;) comme séparateur, pour une ouverture correcte dans Excel en français.
La ligne sep=; indique à Excel le séparateur : conservez-la. La deuxième ligne contient les noms techniques des colonnes : ne la modifiez pas et gardez leur orthographe.
Ajoutez les pièces à partir de la ligne 3. Les cellules facultatives peuvent rester vides.

COLONNES OBLIGATOIRES
- sku : référence interne unique de la pièce.
- name : désignation affichée dans le catalogue.

INFORMATIONS DE LA PIÈCE
- category : catégorie, par exemple Freinage ou Refroidissement.
- pieceBrand : marque de la pièce.
- description : description courte.
- reference : référence OEM ou équivalente.
- referenceType : OEM ou ALTERNATIVE (OEM par défaut).
- images : URL HTTPS d'une photo; pour plusieurs photos, séparez les URL avec | (8 maximum).
- priceHT : prix de vente client hors taxes en TND (facultatif, positif, 3 décimales maximum). Le renseigner fixe le prix en mode manuel et remplace la marge configurée.
- stock : quantité disponible gérée directement par GHORBEL (entier de 0 à 1 000 000). Cette colonne ne modifie pas le stock des pièces partenaires.

COMPATIBILITÉ VÉHICULE (FACULTATIVE)
Si une compatibilité est renseignée, make, model, generation et yearFrom sont obligatoires ensemble.
- make / model / generation : marque, modèle et génération du véhicule.
- yearFrom / yearTo : année de début et année de fin (1900–2100). yearTo peut rester vide.
- engine / engineCode / fuel / displacementCc / powerKw : motorisation; renseigner engine ou engineCode si les caractéristiques moteur sont indiquées.
- variant / bodyStyle / transmission / drivetrain : version et caractéristiques; variant est requis si l’une des trois dernières colonnes est renseignée.

SOURCE ET VÉRIFICATION
- source / sourceReference : origine et référence justificative des données véhicule.
- verified : true uniquement si les données de compatibilité sont vérifiées et qu’une source est indiquée; sinon laisser vide ou mettre false.

RÈGLES DE SAISIE
- Une ligne par référence ou compatibilité. Pour répéter un SKU, gardez le même nom, la même catégorie, la même marque de pièce et la même description.
- Les nombres décimaux utilisent un point (ex. 1.6); ne mettez ni séparateur de milliers ni unité dans les cellules numériques.
- Le fichier doit rester au format CSV UTF-8, avec le point-virgule comme séparateur. Limite : 2 Mo et 2 000 lignes de données.
- L’import commence par une prévisualisation. Vérifiez toutes les erreurs avant de confirmer.
